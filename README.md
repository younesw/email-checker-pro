# Email Checker Pro

## مقدمة
تطبيق سطح مكتب بسيط يساعدك على فحص حسابات البريد الإلكتروني الخاصة بك فقط عبر IMAP و SMTP.

## متطلبات التشغيل
- Python 3.10+
- PyQt5

## التثبيت
```bash
pip install -r requirements.txt
```

## التشغيل
```bash
python main.py
```

## إنشاء ملف EXE
```bash
build_exe.bat
```

## ملاحظات
- استخدم حساباتك فقط
- للحسابات المحمية بـ 2FA استخدم App Password
- لا تستخدم التطبيق على حسابات أطراف ثالثة
